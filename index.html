Conexión pendiente

No se pudo cargar la conexión a Supabase. Revisa tu conexión a Internet y abre la aplicación desde una página HTTPS, preferentemente GitHub Pages. Si el problema persiste, comprueba que el servicio esté disponible.

Esta versión utiliza únicamente la clave pública publishable. Nunca agregues una clave secreta a un archivo HTML.

Ingresar a Aprendeya

Profesor y estudiante ingresan con su propio correo. No necesitas crear un correo para cada curso.

Si activas confirmación de correo en Supabase, debes verificar tu dirección antes de ingresar. Usa cuentas de prueba y evita datos reales de estudiantes en esta etapa.

Configurar mi perfil
